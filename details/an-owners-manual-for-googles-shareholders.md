# An Owner’s Manual for Google’s Shareholders

Google's memo introducing dual-class voting shares to maintain control while raising capital. Created during the company's early public offering preparations, it explains the structure's rationale for long-term decision-making. This internal document provides context on corporate governance in tech startups.
